# everett.boo

Personal blog built with [Tale](https://github.com/chesterhow/tale), a minimal Jekyll theme for storytellers.

## Preview locally

```sh
bundle install
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000`.

## Write

Add Markdown posts to `_posts` using the filename format `YYYY-MM-DD-title.md`.
